## Questions and ideas

Use [GitHub Discussions](https://github.com/PraiseTechzw/interest-loop/discussions) for questions, feature ideas and general discussion. Please search existing threads first.

## Bugs

Open an issue with the **Bug report** template. Include:

- what you expected and what happened,
- steps to reproduce,
- platform (Android / iOS / web), Expo Go or development build,
- app version, and relevant logs if available.

## Security

Never report security issues in public. Follow [SECURITY.md](./SECURITY.md).

## Response expectations

This is an openly maintained project. Issues are triaged as time allows; bug reports with clear reproduction steps are handled first. Pull requests that follow [CONTRIBUTING.md](./CONTRIBUTING.md) and pass CI are reviewed in the order received.
